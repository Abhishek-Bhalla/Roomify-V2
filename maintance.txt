You are working on the Roomify room booking management system.

The application currently has three actors:
1. Requester
2. Approver
3. Admin

I want to introduce a fourth actor:

## New Actor
Maintenance Incharge

This actor is responsible for handling room maintenance requests, updating maintenance progress, and marking rooms as ready for booking after repairs or renovations.

Do NOT replace any existing functionality. Extend the current application while following the existing architecture, coding standards, and UI design.

## Functional Requirements

### 1. New Role
Add a new role called "Maintenance Incharge".

Permissions:
- Login
- Logout
- View assigned maintenance tasks
- View room details
- Accept maintenance tasks
- Update maintenance progress
- Change maintenance status
- Upload maintenance report
- Upload before/after images
- Add remarks
- Mark maintenance as completed
- View maintenance history

This role CANNOT:
- Approve bookings
- Reject bookings
- Create bookings
- Edit rooms
- Delete rooms
- Manage users
- Access reports (except maintenance-related reports)

---

## 2. Room Status Lifecycle

Extend the room status to include:

- Available
- Booked
- Pending Approval
- Under Maintenance
- Maintenance Assigned
- Maintenance In Progress
- Maintenance Review Pending
- Available

Whenever a room enters maintenance, it must no longer appear in room search results or be available for booking.

---

## 3. Approver Workflow

On the booking details page (or room management page), add a new action:

"Mark Room Under Maintenance"

When clicked:

- Ask for maintenance reason
- Select issue category
- Select priority
- Add optional remarks

Issue Categories:
- Electrical
- HVAC / AC
- Furniture
- Cleaning
- Renovation
- Plumbing
- Internet
- Projector
- Other

Priority:
- Critical
- High
- Medium
- Low

After submission:

- Room status becomes "Under Maintenance"
- Create a Maintenance record
- Assign the task to the Maintenance Incharge
- Send an email notification immediately
- Send an in-app notification
- Prevent new bookings for that room

## 6. Completion Workflow

After the Maintenance Incharge submits the report:

Status changes to:

Maintenance Review Pending

Automatically notify:

- Approver
- Admin

Approver can:

Approve Completion

or

Request Additional Work

If approved:

Room status becomes Available.

The room immediately appears again in search results and can be booked.

If rejected:

Status returns to:

Maintenance In Progress

Maintenance Incharge receives a notification with the comments.
